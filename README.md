# Quiz-App
This a four question multiple choice quiz. When the user the selects an answer one of two things may happen. If the user gets the question correct the answer will be highlighted in green. If the user selects the wrong answer, that answer will be highlighted red and the correct answer will be highlighted in green. Once an answer is selected the user will not be able to select anymore answers and will need to click on the "Next" button to move onto the next question. Once all questions are asked the user will get a score and the option to retake the test. 

Each question and its relevent answers are stored in an object. Every object is stored in an array. When the webpage loads the displayQuiz functions loops through one of the objects and displays the question, as well as the answers in a randomized sort. There is a gloabal correctAnswer variable to keep track of the correct answer for every question. There is a click event listener on the answerContainer div which contains the four answers to keep track of which answer is being selected by the user. There is a global correctAnswerTally variable to keep track of how many correct answers the user got and a highlightOrUnhighlight function that highlights the answers and unhighlights the answers based on where in the quiz the user is. 

Also because the question and answers are held in objects that keep track of the questions, correct answers, and wrong answers, more questions and answers can be added to the quiz while keep the foundamentel logic intact.
